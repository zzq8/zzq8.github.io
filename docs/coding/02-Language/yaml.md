## yaml 常用语法

\# 号代表是注释

末尾换行还能用后缀控制：
- | 或 >：末尾保留一个换行（默认）
- |- 或 >-：去掉末尾换行（最常用，写脚本/字符串必加）
- |+ 或 >+：末尾所有空行全保留
一句话：| 老实保留，> 把换行揉成空格；- 去尾，+ 全留。



一般日常用最多 `|` / `|-`

```yaml
# 方案一：单行文本直接内联（推荐，短文本别用块标量）
- q: 你们是一直在做 agent 平台，业务是其他部门做的吗？
  a: 是的。agent 平台

# 方案二：真有多行内容才用块标量
- q: 你们是一直在做 agent 平台，业务是其他部门做的吗？
  a: |
    是的。agent 平台
    第二行内容
```
